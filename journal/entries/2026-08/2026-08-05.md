### Summary
The developer fixed a test that was silently passing when it should have been catching missing rules. The test named "classifies every rule" had three negative assertions—checking that no rule carried both loading mechanisms, none was bare, and the summary line said so—but all three would pass even if the traversal skipped an entire directory, since a rule that was never visited couldn't be misclassified.

The developer added a positive assertion that derives the expected rule paths from the copied rules directory and checks that each one has an inventory row. Now the test reports every missing rule instead of stopping at the first failure. The developer verified the fix by mutation testing, constraining the script's traversal to one directory level, which turned the test red and named the five nested language rules that had been invisible to the old test. After confirming the mutation worked, the developer reverted it.
