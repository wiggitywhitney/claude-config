The push gate is `.claude/skills/verify/scripts/check-diff-review-required.sh`, registered as a `PreToolUse` hook on `Bash` in `.claude/settings.json`. It's a shell script, so it can only refuse to proceed; it cannot spawn a sub-agent itself. The refusal is the whole mechanism—it makes the review step mandatory rather than a habit that decays. The gate matches on the `git push` command text, strips both quoted strings and heredoc bodies before matching (the latter was necessary because the commit message describing the gate itself contained the words it matches on, and quote-stripping never sees inside a heredoc body), and keys the verdict lookup to a hash of the diff content rather than a commit SHA, so adding or amending a commit invalidates the verdict deliberately.

Both staleness properties were demonstrated with real `git push --dry-run` attempts that were refused: one with no verdict at all, one carrying only a verdict for a previous commit's diff. The gate blocked its own first commit for the heredoc reason, which was fixed and covered by two new tests.

The developer wrote 30 bats assertions across three new test suites—`tests/compute-diff-key.bats` (10 tests), `tests/check-diff-review-required.bats` (12 tests), and `tests/record-diff-review.bats` (8 tests)—all passing. The developer also documented the work in `docs/research/diff-reviewer-trial.md` and updated `PROGRESS.md` and the PRD to reflect what was built and what remains.

The trial is incomplete. The reviewer hasn't been scored against the three benchmark diffs it was designed around, so the catch count—the number this exercise exists to produce—doesn't exist yet. Three worktrees are left checked out at the commits that introduced each miss rather than the ones that fixed them, so reviewing a correction wouldn't measure whether the reviewer objects to accurate work. Scoring, cost measurement, and whether the interruption is tolerable are all outstanding.

**DECISION: Push gate registered in project settings rather than globally** (Implemented) - FILES: .claude/settings.json

**DECISION: Reviewer hunts for four specific defect classes from this repository's actual failures** (Implemented) - FILES: .claude/agents/diff-reviewer.md
  - A claim asserted as fact whose stated basis is already disproved elsewhere in the repository
  - A count, total, or figure that disagrees with the tool that generates it
  - A reference to a file, script, flag, or command that no longer exists
  - An assertion of state with no observation beside it
  - Generic code review is explicitly out of scope; these four are why the reviewer was dispatched

**DECISION: Heredoc bodies stripped before matching push command** (Implemented) - FILES: .claude/skills/verify/scripts/check-diff-review-required.sh, tests/check-diff-review-required.bats

  - This gate was copied from a hook that already had a defence against this class, and inherited the defence without its full coverage
