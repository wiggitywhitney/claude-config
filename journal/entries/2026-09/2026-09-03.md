### Summary
The developer documented Decision 77, which closes a question about whether Milestone D2's transcript extraction should use a committed, re-runnable script. The decision ratifies an implementation made provisionally on 2026-09-02, establishing that the script will handle enumeration and redaction deterministically while the model classifies the human turns it extracts.

The documentation records two substantive arguments supporting this choice: Milestone D2's deliverable is a completeness claim ("every decision found in the transcripts"), which a model can only support as "every decision I noticed"—a weak foundation for the one verification step meant to catch what earlier checks missed. Additionally, the transcripts contain credentials and customer data; manual redaction across hundreds of kilobytes is unreproducible and the likeliest path for a secret to reach a tracked file. The counter-argument—that this decides early, contrary to the phase structure's intent—is also recorded.

The documentation adds two concrete constraints that follow from the decision: Milestone A3's redaction policy is not fully mechanizable, so the script covers deterministic pattern work while a model reviews the residue before anything is committed to a tracked file, preserving the structural guarantee that raw extracts stay outside the repository. The script also requires test coverage including a case that verifies a known credential shape does not survive redaction, since this is the one script in the project whose silent failure would be a security defect rather than a wrong number.
