### Summary
The developer added a third test case to the pair-detection benchmark in the PRD documentation. The new case documents two byte-identical PR template files (`.github/PULL_REQUEST_TEMPLATE.md` and `.github/pull_request_template.md`) that sit in the same directory and differ only by filename case. This pair is invisible to both candidate detection classes—the same-basename-across-directories class misses it by design since it only looks across different directories, and the near-duplicate-content class would need to scan within directories rather than across them to catch it. The pair also hides entirely on case-insensitive filesystems despite being tracked separately by git. The developer documented this discovery as a requirement for the benchmark: any detection class that cannot find two identical files sitting next to each other is not ready for use.
