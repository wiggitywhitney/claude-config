## 2:13:23 PM CDT - Commit: 99d8626

### Summary
The documentation for OpenTelemetry Python gotchas was updated to clarify the difference between `sys.exit()` and `os._exit()` in the context of span cleanup. The entry explains that `sys.exit()` raises a `SystemExit` exception, which triggers a `with` block's `__exit__` method normally, allowing spans to close properly. By contrast, `os._exit()` terminates the process at the C level without unwinding the Python call stack, causing any open spans to leak. The documentation notes this distinction matters for span-leak detection rules, as treating both as equivalent produces false positives on legitimate `sys.exit()` calls within spanned functions.
