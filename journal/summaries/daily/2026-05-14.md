## Key Decisions

- **Drop `/skill-creator eval` advisory from `/prd-done` entirely.** The eval process is too expensive (6+ parallel agents, ~300K tokens, several minutes) to recommend for routine skill updates. If eval is ever surfaced in the future, it should guide users to decide whether it's worth running rather than recommending it unconditionally.

- **Extend `suggest-write-prompt` hook to fire for PRD files, rules files, and non-standard prompt filenames.** The hook was missing file types that agents interact with regularly and required additional pattern matching to catch both absolute and relative paths.

- **Create a separate `suggest-planning-handoff` hook instead of mixing into `suggest-write-prompt`.** Planning handoff (completeness of context) and implementation handoff (quality of prompts) are different concerns. The new hook fires only at actual handoff moments (when `gh issue create` succeeds or a new PRD file is created) and asks three concrete questions about whether the document has enough context for a future agent to act on.

- **Fire `planning-handoff` hook only on new file creation, not edits.** Using the Write tool (creates) versus Edit tool (modifies) distinction prevents the hook from firing repeatedly during mid-session PRD refinement.

- **Register `suggest-planning-handoff` hook in both Bash and Write PostToolUse matchers.** The hook needs to catch both `gh issue create` (via Bash) and new PRD file creation (via Write).

- **Fix path matching in both hooks to handle relative paths.** Glob patterns like `*/prds/*` missed relative paths like `prds/93-feature.md`. Added simpler patterns (`prds/*`, `rules/*`) to catch both absolute and relative paths.

- **Extend `/make-autonomous` with twelve new permissions for autonomous child sessions.** Autonomous sessions need to run tests (`npm test*`, `npm run build*`, `npm run *`, `npx vitest*`, `pytest*`, `bats*`), manage tasks (`TaskCreate`, `TaskUpdate`, `TaskGet`, `TaskList`), spawn sub-agents (`Agent`), and schedule wake-ups (`ScheduleWakeup`) without hitting confirmation prompts.

- **Fix `install-git-hooks.sh` to resolve relative paths correctly.** The `git rev-parse --git-path hooks` command returns a relative path when `core.hooksPath` isn't set, causing hooks to install into the wrong directory. The fix resolves that path against the target repository.

- **Run tests on every push, not just when a pull request exists.** Refactored the pre-push hook to extract the test command once at startup and use it in both PR and non-PR code paths. This prevents broken tests from accumulating through multiple commits before CI catches them at PR creation time.
