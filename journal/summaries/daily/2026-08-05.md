## Key Decisions

- **Introduce a handoff mechanism for D1's findings instead of writing to a spec C2 hasn't created yet** — D1 writes to a separate research document; C2 absorbs it while drafting the spec, restating findings in the spec's terms rather than pasting directly. Preserves execution order and sign-off-once property while maintaining separation between research and specification.

- **Drop the after-measurement of approval-prompt rate and tear down the permission instrument** — No published benchmark exists to compare against; the mechanism already predicts the effect through arithmetic; evidence that matters comes from practitioners' actual setups, not before-and-after comparisons.

- **Remove the `vale-on-edit` hook** — Fires in every repository to serve one repository last touched in May; project-specific linter belongs in that project's configuration or CI, not in global hooks.

- **Repair the `post-write-codeblock-check` hook by collapsing its passthrough layer** — Shell wrapper's entire body re-invoked Python script; wrapper deleted so hook calls checker directly. Avoids duplicating the markdown-file-type decision across two files.

- **Repair the `suggest-branch-cleanup` hook to suppress redundant branch-deletion advice** — `gh pr merge --delete-branch` already removes the branch; hook was advising deletion regardless. Now recognizes both flag spellings and only keeps the half `gh` doesn't handle.

- **Remove the `check-contributing-freshness` hook** — Never produced output; mechanism is prior art for coupled-pair detection but the implementation was blind to actual drift it was built for.

- **Repair the `check-running-clusters` hook to make cloud-cost alarm actually work** — GKE half had never fired because gcloud command failed silently when no project was configured. Now resolves project explicitly and reports missing configuration as visible problem rather than absence of clusters.

- **Remove the `/continue` and `/post-compact` skills** — Both relied on dead `Status: In Progress` marker that nothing writes; `/continue` was never used; `/post-compact` premise is outdated.

- **Remove the `auto-reanchor` PostCompact hook** — Could never have worked: wrote to stderr on exit 0 (which reaches debug log only, never the model); PostCompact event supports no context injection; PRD detection was independently broken.

- **Stop loading personal-context file into every session and retire the machinery** — Nightly job had been failing for four months with "Operation not permitted"; file was empty; four months of working without it treated as sufficient evidence it wasn't needed.

- **Document how hooks actually deliver messages to Claude** — Stderr from clean exit reaches debug log only; context must be nested inside wrapper naming event; post-compaction event cannot inject context at all. Testing with realistic payloads revealed these rules.

- **Fix checks that couldn't distinguish between "found nothing" and "could not look"** — Cluster alarm's local half, two configuration scanners, and teardown command all silently swallowed errors. Now abort or report failures explicitly instead of producing wrong answers.

- **Add boundary requirement to both `@`-reference scanners** — Two scripts were disagreeing about what counts as a reference; added whitespace/end-of-line/closing-paren boundary to both so they agree.

- **Document sentence fragment prohibition and first-person voice requirement in writing guide** — Fragments aren't acceptable even as punchy hooks; episode and talk posts should refer to host in first person, not third person.

- **No coupled-pair warning hook and no general coupled-pair detection mechanism** — Pair enumerator returned 87 candidates and matched none of the real pairs found. All real pairs were same knowledge under different names; no filename pattern can relate them.
