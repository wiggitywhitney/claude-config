# Daily Summary — 2026-09-03

## Narrative

The developer documented Decision 77 today, formalizing a choice about how Milestone D2 should extract and process transcripts. The decision had been implemented provisionally back on 2026-09-02, but needed to be officially recorded. The core call: use a committed, re-runnable script to handle enumeration and redaction deterministically, while a model classifies the human turns that the script extracts.

The reasoning came down to two main points. First, D2's whole deliverable is a completeness claim—"every decision found in the transcripts"—but a model can only ever support "every decision I noticed," which is a weak foundation for the one verification step meant to catch what earlier checks missed. Second, the transcripts contain credentials and customer data, and manual redaction across hundreds of kilobytes is both unreproducible and the most likely way a secret reaches a tracked file. There was a counter-argument on record too: this decision commits early, which goes against the phase structure's intent. But the developer went with the recommendation anyway.

The documentation also locked in two concrete constraints. Milestone A3's redaction policy isn't fully mechanizable, so the script handles the deterministic pattern work while a model reviews the harder judgment calls before anything gets committed to a tracked file—this preserves the guarantee that raw extracts stay outside the repository. The script also needs bats test coverage with a specific case: verify that a known credential shape doesn't survive redaction, since this is the one script in the project where silent failure would be a security defect rather than a wrong number.

## Key Decisions

- **Milestone D2 transcript extraction uses a committed, re-runnable script for enumeration and redaction; the model classifies extracted human turns.** Rationale: D2's deliverable is a completeness claim that a model can only support weakly, and manual redaction of transcripts containing credentials is unreproducible and a likely path for secrets to reach tracked files.
- **Milestone A3's redaction policy requires hybrid mechanization with model review for judgment categories.** This preserves the structural guarantee that raw extracts stay outside the repository.
- **Transcript redaction script requires bats test coverage including a credential non-survival assertion.** This is the one script whose silent failure would be a security defect rather than a wrong number.
