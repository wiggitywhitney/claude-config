# Daily Summary — 2026-10-07

## Narrative

The developer wrapped up Milestone B1 of the claude-config audit by consolidating research findings into the project's documentation and configuration files. The work centered on documenting four areas of investigation: Claude Code's sandbox behavior, CodeRabbit CLI quirks, context-loading mechanics, and code-review implementations.

For the sandbox, the developer recorded several gotchas discovered through live testing on macOS. The `--dangerously-skip-permissions` setting still allows network access to unlisted hosts unless stricter allowlist rules are enabled. Go-based tools like `gh` and `vals` failed inside the sandbox with certificate and timeout errors, though a one-line workaround exists. The `excludedCommands` setting matches literal command text rather than child processes invoked by scripts. Two macOS-specific issues were also documented involving git protocol failures and test runner flags. The developer also found that enabling the sandbox requires three settings configured together because defaults leave escape hatches open.

The context-loading research closed a six-week-old question: project-level `@`-imports never enter context at all, making their byte cost zero. The reviewer investigation uncovered that three code-review implementations coexist, with the personal fork shadowing the bundled skill, and that Viktor's configuration contains a disabled all-Claude alternative rather than evidence of actual testing.

The developer added several corrections to existing guidance. A code-review bot's refusal to re-review means the check already happened, not a reason to keep asking. The installer gotcha was clarified to explain that hooks auto-install on every dashboard startup with no separate manual step. The sandbox's escape hatch was corrected to be model-mediated rather than automatic. The permission-modes document was updated to reflect that the sandbox's per-domain prompt class is largely obsolete.

Configuration-wise, the developer added `"feedbackDrafts": "off"` to turn off the assistant's background drafting of product feedback during sessions.

Five new daily journal summaries were created documenting specific investigation sessions from September 11, 18, 19, 20, and 21, capturing the audit work's process and findings. The git-workflow rules received targeted updates clarifying credit-usage prompts, the CLI's self-update behavior, and how to detect when a code-review bot has actually reviewed a commit by checking the review's summary comment and check description.
