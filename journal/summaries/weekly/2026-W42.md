# Weekly Summary — 2026-W42

## Week in Review

The developer spent the week resolving documentation inconsistencies and closing out a key research question about how Claude Code handles imported files during context compaction.

Early in the week, they cleaned up several gotchas guides that had accumulated incorrect advice. The tree-sitter guide needed a fix: comparing nodes by `.startIndex` isn't safe even for siblings, because error recovery can insert zero-width `MISSING` nodes that share a start index with adjacent nodes. They switched the guidance to use `.id` instead, which is stable and unique within a tree. They also refined the is-scoring guide's git status check to exclude directories being partially checked out, since that operation always stages files there anyway.

Alongside the gotchas work, they carried revisions through multiple documentation files related to a Claude config audit redesign, softening language around version inference and marking outdated findings as superseded. They committed pending journal entries documenting research from the previous week, including a critical reversal: project-level `@`-imports from `.claude/CLAUDE.md` actually do load into context when the import path is correct—contradicting an earlier finding that had been based on incorrect pathing.

They also documented three quirky behaviors of the journal post-commit hook that look like failures but work as intended: it exits with status 2 for journal-only commits, dirties the working tree a few seconds after every commit, and can regenerate summary files that collide with copies on other branches.

By mid-week, they'd narrowed the compaction-survival documentation to separate what was confirmed (user-level imports survive compaction) from what remained open (project-level import survival). This distinction turned out to matter: by the end of the week, they ran a fresh measurement and found that imported files inside the project's working directory do survive compaction and get re-read from disk afterward. Files outside the working directory never load unless the project has explicitly approved external imports. This explained a previous August observation where two imported rule files seemed to vanish—they'd actually never loaded in the first place. They also discovered that compaction can now be triggered in a scripted session using a single `claude -p --input-format stream-json` process, something an earlier note claimed wasn't possible. They updated four documentation files with these findings and cascaded the decision into related milestones.
